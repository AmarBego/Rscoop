### Release Notes 1.10.0

#### New Features

* Edit package manifests directly in the Manifest tab, with live syntax highlighting, JSON validation, and automatic backups when saving.
* Restore the latest manifest backup from the compact actions menu; the current file is backed up before restoring.
* Open manifests in your preferred text editor or IDE, then reload saved changes in rScoop.
* Get an “Upstream changed” notice when an edited manifest conflicts with a bucket update. Review your version and upstream without losing your draft, or jump straight to the manifest from update results and notifications.

#### Bug Fixes

* Fixed the installer launch regression that could leave Scoop commands, Doctor checks, and tray icons broken until rScoop was restarted.
